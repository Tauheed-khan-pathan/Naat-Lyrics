Nabi Aap Ko Maine Dekha Nahi Hai

Naat • Shayar: Maulana Abu Jafar
Naat Khawan: Mudassir Abdullah, Akhyar Ahmad
salle-'ala sayyidina, sallallaahu 'alaihi w sallam salle-'ala sayyidina, sallallaahu 'alaihi w sallam haan ye baat sach hai, haqeeqat yahi hai nabi ! aap ko main ne dekha nahin hai n daur-e-muhammad mein paida hua main n saathi safar ka kabhi ban saka main n aaqa ki aawaaz tak sun saka main n ghazwaat mein mushrikon se lada main n hijarat ki lazzat hui mujh ko haasil n ho paaya ansaar ki saf mein shaamil nabi aap jis dam the ghaar-e-hira mein koi zaad-e-raah bhi n pahuncha saka main magar sach hai ye bhi, qasam hai khuda ki mohabbat mujhe aap se hai, nabi ji ! salle-'ala sayyidina, sallallaahu 'alaihi w sallam salle-'ala sayyidina, sallallaahu 'alaihi w sallam mujhe aap ke ghar se, dar se mohabbat safar se mohabbat, hazar se mohabbat mujhe aap ke har pehr se mohabbat har ik raaste, raah-guzar se mohabbat wo eema-e-shaqqul-qamar se mohabbat zaqan se, dehn se, nazar se mohabbat nubuwwat ki jis ne gawaahi di, aaqa ! haan us goh se, us hajar se mohabbat ye be-dhang si meri mohabbat ka tohfa kya us ki ijaabat ka hai koi rasta salle-'ala sayyidina, sallallaahu 'alaihi w sallam salle-'ala sayyidina, sallallaahu 'alaihi w sallam n bu-bakr sa main rafeeq-e-safar hoon n 'usmaan-o-haidar hoon, n main 'umar hoon n talha, n hamza, s'eed-o-s'ad hoon anas jaisa khaadim n khaalid asad hoon n main ibn-e-'auf-o-zubair-o-'ubaida n main bu-dujaana, m'aaz-o-qataada n araqam, n akhanas, bilaal aur yahya n misl-e-yasaar aur yaasir n yaa'la main in sab ke qadmon ke zarron ka zarra magar, ai nabi ! aap ka hoon main shaida salle-'ala sayyidina, sallallaahu 'alaihi w sallam salle-'ala sayyidina, sallallaahu 'alaihi w sallam
