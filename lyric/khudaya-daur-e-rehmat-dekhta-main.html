Khudaya Daur-e-Rehmat Dekhta Main

Naat • Shayar: Azizullah Ghalib
Naat Khawan: Muhammad Anas Nazeer
khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main unheen ke dar pe hoti subh meri wahin par shaam-e-furqat dekhta main nabi ka husn-e-tal'at dekhta main khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main madeene ki gali mein sar jhukaaye rasool-e-haq ki 'azamat dekhta main nabi ka husn-e-tal'at dekhta main khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main sahaabi kaash main hota nabi ka karam ki har 'inaayat dekhta main nabi ka husn-e-tal'at dekhta main khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main jabeen-e-shauq sajde mein jhuka kar 'ibaadat ki haqeeqat dekhta main nabi ka husn-e-tal'at dekhta main khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main bichhaata apni palkein un ki reh mein 'ajab rang-e-'aqeedat dekhta main nabi ka husn-e-tal'at dekhta main khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main kabhi jo masjid-e-nabwi mein hota jamaal-e-bazm-e-jannat dekhta main nabi ka husn-e-tal'at dekhta main khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main khateeb-e-kibriya ki haq-bayaani wo e'jaaz-e-fasaahat dekhta main nabi ka husn-e-tal'at dekhta main khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main uhud ki khaak-e-aqdas choom leta fidaakaaron ki himmat dekhta main nabi ka husn-e-tal'at dekhta main khudaaya ! daur-e-rehmat dekhta main nabi ka husn-e-tal'at dekhta main 'ata hoti basaarat mujh ko, ghaalib !
